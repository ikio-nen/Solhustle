Takes you to Auth0, the hosted login page, to enter your credentials — your password never touches this app.

Auth0 will return to a different origin than this page. This server serves this origin, but AUTH0_CALLBACK_URL points at the configured origin, so a finished sign-in lands there and no session is issued here. Either serve the app on the callback's origin, or add this origin to the Auth0 application's Allowed Callback URLs and point AUTH0_CALLBACK_URL at it.
Auth0 is not configured on this server. Set AUTH0_ISSUER_BASE_URL, AUTH0_CLIENT_ID and AUTH0_CLIENT_SECRET to switch on hosted sign-in, then whitelist /auth/auth0/callback as an Allowed Callback URL, /login as an Allowed Logout URL and the app origin as an Allowed Web Origin. Sign-in below stays local until then.
